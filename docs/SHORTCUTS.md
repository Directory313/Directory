# Keyboard Shortcuts

All shortcuts can be changed in **Settings → Shortcuts** (or F1). The command palette
(**Ctrl+Shift+P**) lists every command with its current shortcut.

| Action | Shortcut |
|---|---|
| **File** | |
| Open project | Ctrl+O |
| Save / Save As | Ctrl+S / Ctrl+Shift+S |
| Import media | Ctrl+I |
| Export | Ctrl+M |
| Render queue | Ctrl+Alt+M |
| Settings | Ctrl+, |
| Command palette | Ctrl+Shift+P |
| Shortcut reference | F1 |
| **Edit** | |
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y) |
| Cut / Copy / Paste / Duplicate | Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D |
| Delete / Ripple delete | Delete / Shift+Delete |
| Select all / Deselect | Ctrl+A / Ctrl+Shift+A |
| **Playback** | |
| Play / Pause | Space |
| Play from work-area start | Shift+Space |
| Previous / next frame | PageUp / PageDown, `,` / `.` |
| Back / forward 10 frames | Shift+PageUp / Shift+PageDown |
| Go to start / end | Home / End (Ctrl+Left / Ctrl+Right) |
| Shuttle | J / K / L |
| **Timeline** | |
| Split at playhead | S, Ctrl+K, Ctrl+Shift+D |
| Move in / out point to playhead | [ / ] |
| Trim in / out to playhead | Alt+[ / Alt+] |
| Previous / next edit point | Ctrl+Up / Ctrl+Down |
| Set work area in / out | I / O |
| Add marker | M |
| Show animated properties | U |
| Toggle snapping | N |
| Zoom timeline / fit | = / - / Shift+Z |
| Easy ease / ease in / ease out | F9 / Shift+F9 / Ctrl+Shift+F9 |
| Hold keyframes | Ctrl+Alt+H |
| Copy / paste keyframes | Ctrl+Alt+C / Ctrl+Alt+V |
| Create compound clip | Ctrl+G, Ctrl+Shift+C |
| **Layers** | |
| New text / solid / null / adjustment | Ctrl+Alt+T / Ctrl+Alt+Y / Ctrl+Alt+Shift+Y / Ctrl+Alt+A |
| Lock / hide | Ctrl+L / Ctrl+Shift+H |
| Bring forward / backward | Ctrl+] / Ctrl+[ |
| Bring to front / send to back | Ctrl+Shift+] / Ctrl+Shift+[ |
| Nudge selected layer | Arrow keys (Shift = 10 px) |
| **Viewer tools** | |
| Select / Hand / Zoom | V / H / Z |
| Text / Rectangle / Pen | T / Q / G |
| Zoom to fit / 100% | Shift+/ / / |
| Safe areas / grid / rulers | ' / Ctrl+' / Ctrl+R |
| **Window** | |
| Workspaces | Alt+1 … Alt+8 |
| Maximise active panel | ` |
| **Composition** | |
| New composition | Ctrl+N |
| Composition settings | Ctrl+Alt+K |
